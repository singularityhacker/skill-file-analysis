What's Unique to Each Pack

Capabilities only found in one skill pack -- and what nobody covers

Only in Gstack

iOS QA on Real Hardware
Vision-driven agent loop on a physical iPhone via USB CoreDevice tunnel. Screenshot, analyze, decide, act, verify.
Post-Deploy Canary
Periodic screenshots, baseline comparison, anomaly alerts. Monitors production after every deploy.
Scrape-to-Skill Pipeline
/scrape pulls data from a page, /skillify codifies the flow into a permanent browser-skill running in ~200ms.
Developer Psychographic
/plan-tune builds a dual-track profile (declared vs observed preferences). "Stop asking me that" actually works.
Security Audit (CSO)
OWASP-scoped security audit with PII/secrets redaction. The only pack with a dedicated security skill.
Cross-Session Decision Store
Append-only, event-sourced JSONL. Decisions persist, are resurfaced before re-deciding, support superseding and redacting.

Only in Pstack

24 Codified Principles
Engineering rules as first-class skills agents must cite when applied. Laziness protocol, boundary discipline, fix root causes.
Arena (Competitive Design)
Fan out N parallel candidates at the same task. Pick a base, graft the best parts from losers, verify result.
Comment Sicko
A deliberately extreme anti-comment reviewer persona. Strips comments, fixes at root cause, encodes constraints as types/tests/lints.
Automate-me
Mines your chat history to generate a personal -mode skill. Turns Pstack into a platform for your own workflow.
Benny Bug Pipeline
Slack issue -> triage -> reproduce (through real UI, twice) -> bounded PR with before/after proof. Production-grade automation.
33 Cataloged AI Slop Patterns
The most exhaustive anti-slop inventory: em dashes, hedging, filler, abstract metaphors, chatbot phrases. Each with a fix.

Only in Matt's Skills

Grilling Primitive
Frontier-based interview rounds: ask all independent questions at once, then recompute. The core beneath 5 different skills.
Teach (Any Subject)
Stateful learning workspace with missions, quizzes, learning records. Users learn Korean, piano, guitar, certifications.
Wizard
Generates interactive bash scripts for manual human procedures. Credential setup, migrations, service provisioning.
Tracer-Bullet Tickets
Vertical-slice decomposition with explicit blocking edges. Each ticket is demoable. No horizontal "build all the DB first."
Wait-What (3 Lines)
Instead of telling the agent "be concise," says "wait, you lost me." Triggers re-explanation. Three lines by design.
Prototype Preservation
Prototypes land on prototype/<name> branches. Never deleted, never merged. Throwaway code as cited artifact.
